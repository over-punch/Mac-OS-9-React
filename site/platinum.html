@liiift-studio/mac-os9-ui/platinum

The Mac OS 9 interface, without React.

Everything below is plain HTML with mac- classes and four framework-free behaviour modules. There is no React on this page. Open the console and check — window.React is undefined, and the only script is a 12 kB ES module. 

import '@liiift-studio/mac-os9-ui/tokens';
import '@liiift-studio/mac-os9-ui/platinum.css';
import { disclosure, menu, balloon, stepper } from '@liiift-studio/mac-os9-ui/platinum';
